# Teaboom — адаптивная карточка товара

Демонстрационный frontend-проект по тестовому заданию: карточка товара «Ананасовый улун».

## Стек
- HTML5 — семантическая структура и доступные элементы управления
- CSS3 — Flexbox, Grid, адаптивная верстка, hover/focus states
- Vanilla JavaScript — выбор фасовки, обновление цены и артикула, количество, демонстрационная корзина, избранное и мобильная навигация

## Запуск
Откройте `index.html` в браузере. Установка зависимостей и backend не нужны.

## Реализовано
- адаптивный интерфейс для desktop, tablet и mobile;
- четыре варианта фасовки с обновлением текущей цены, старой цены, скидки и артикула;
- управление количеством товара;
- демонстрационная корзина со счётчиком;
- кнопка избранного и мобильное меню;
- блок с рекомендациями по завариванию;
- семантические подписи, состояния `aria-pressed` и `aria-live`.

## Примечание
Корзина демонстрационная — серверная часть не подключена. Цены и артикулы соответствуют данным тестового задания. Визуализация чая сделана средствами CSS, поэтому основная иллюстрация не зависит от внешнего изображения.
